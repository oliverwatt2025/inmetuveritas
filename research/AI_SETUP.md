# Optional AI evidence curation (development)

The daily analysis is fully functional without an OpenAI account or API key. With a key, an AI model may **only select up to three already-verified evidence IDs**. The text shown to readers remains deterministically generated by the evidence engine.

## Enable securely
1. Generate an OpenAI API key at https://platform.openai.com/api-keys and set an appropriate project budget.
2. GitHub repository: Settings → Secrets and variables → Actions → New repository secret.
3. Name the secret `OPENAI_API_KEY` and paste its value. Never put it in repository code, commits, Cloudflare environment variables for browser rendering, chat messages or screenshots.
4. Optionally set repository variable `OPENAI_COMMENTARY_MODEL` once validated against a permitted model; default is `gpt-5-mini`.
5. On GitHub Actions, dispatch `Daily macro update` against `market-intelligence-foundation`.
6. Inspect `public/market_intelligence.json` → `editorialCommentary.mode`: `AI_CURATED` confirms validated AI selection, `RULE_BASED` indicates a safe fallback, and `UNAVAILABLE` indicates no fresh verified evidence.

**Operational note:** GitHub Secrets are repository-scoped; a key enables AI for any workflow that explicitly reads it. The current main-branch workflow does not reference this key. Keep the draft PR unmerged until checks pass.

The API may incur separate usage charges; a ChatGPT subscription is not an API billing entitlement.
